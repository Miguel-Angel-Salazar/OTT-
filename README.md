#  Proyecto OTT - Clon de MUBI (Paradigmas de Programación)

Este es el repositorio de nuestro proyecto para la materia de Paradigmas de Programación. Es un prototipo funcional de una plataforma de streaming de video bajo demanda, inspirada en el diseño y funcionamiento de MUBI.

El objetivo principal del proyecto es aplicar el patrón arquitectónico MVC (Modelo-Vista-Controlador) y gestionar la persistencia de datos y sesiones de usuario en un entorno web.

##  Tecnologías que usamos

Decidimos mantener la arquitectura simple y robusta usando renderizado del lado del servidor:
* **Backend & Enrutamiento:** Python 3 con Flask.
* **Base de Datos & Autenticación:** Supabase (PostgreSQL + Auth).
* **Frontend:** HTML5, CSS puro (diseño oscuro) y Vanilla JS (sin frameworks complejos).
* **Plantillas:** Jinja2.
